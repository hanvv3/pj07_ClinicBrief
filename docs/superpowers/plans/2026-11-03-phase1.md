# Phase 1 deliverable implementation plan

**Goal:** Prove researched example selection through Korean brochure/private notes to real PDF and DOCX.
**Architecture:** Local Python HTTP app, SQLite snapshots, static Korean UI, separate document renderer.
**Tech stack:** Python 3.11+, standard library, python-docx, LibreOffice, Korean Noto fonts.
**Spec:** `specs/approval_candidate_spec.en.md`; design: `docs/superpowers/specs/2026-11-03-phase1-design.md`.

## Global constraints

Phase 1 only; non-sensitive local examples. No clinical instructions, promotion, segmentation, sales analytics, invented contacts or citations. Separate representative notes from exports. Label prepared examples and currentness truthfully. Keep original specification files unchanged.

## Review focus

1. Double submit and stale browser revisions must not create divergent saved content.
2. PDF failure must preserve DOCX and permit bounded retry.
3. Sender text must remain literal and cannot inject XML, HTML or commands.
4. Saved content must reopen unchanged; old downloads must be invalidated on edits.
5. Local-only HTTP must reject foreign origins and unexpected hostnames; never imply SaaS privacy.
