# Phase 2 implementation plan

**Goal:** Authenticated live research → selected topic → both composition modes → correction/review → saved consistent outputs.
**Architecture:** Reuse local Python/SQLite rendering workflow; add separated provider, auth and durable bounded jobs. Cloud rollout remains Phase 3.
**Spec:** `specs/approval_candidate_spec.en.md`; `docs/superpowers/specs/2026-11-03-phase2-design.md` (exact contracts).

## Review focus

- Cross-account draft/note/input/job/download access must return no content.
- Company text and revision instructions must never enter public search; tool/content injections cannot elevate evidence to rules.
- Duplicate requests, failed responses and server restart must not silently repeat paid work.
- Source snippets/invented citations, undated/stale claims and unsupported central claims must not become ready facts.
- Revisions must update both audience materials atomically and invalidate old review/downloads.

## Tasks

- [x] Provider and evidence: add `provider.py`, schemas/prompts, meaningful tests for transport, evidence trace, safety audit, and no web tools during private composition. Verify with injected transport first; real key smoke test separately.
- [x] Auth and jobs: add `auth.py`, `jobs.py`, tests for password/session expiry, isolation, idempotence, quotas, progress, restart interruption, and terminal deletion.
- [x] Integration: owner-aware draft store/service, private live candidate snapshots, compose/revision jobs, cookie/CSRF routes; preserve unowned legacy work without account takeover. Test two-account end-to-end cases and failure behavior.
- [x] UI: sign-in, live vs example browsing, supported company text and processing confirmation, progress/reload/recovery, revision requests, source dates, saved work and deletion. Keep both-audience review/export behavior.
- [x] Verification: full tests, real API research/composition for non-sensitive sample if existing key is configured, browser and final artifact checks, independent review, checkpoint and operator README update.
