# AMIE R2 산출물 검증

검증일: 2026-11-03. 대상: `amie-reviewed-r2.docx`, `amie-reviewed-r2.pdf`. 문서와 제품 코드는 수정하지 않았다.

**결과: 산출물 검증 통과.** DOCX를 번들 LibreOffice로 재렌더링한 2페이지와 실제 PDF를 번들 Poppler로 렌더링한 2페이지, 총 4개 이미지를 모두 직접 확인했다. 잘림, 겹침, 빈 페이지, 한글 글리프 누락은 없다. 기존 A4 텍스트 구성을 유지하며 삽화형 템플릿을 적용한 결과가 아니다.

| 점검 | 결과 |
| --- | --- |
| 페이지 수 | DOCX 재렌더링 2페이지, 실제 PDF 2페이지 |
| 편집성과 내용 일치 | DOCX에 편집 가능한 OOXML 텍스트 노드 20개. DOCX 본문·재렌더링 PDF·실제 PDF의 공백 정규화 텍스트가 일치함 |
| 한글 글꼴 | PDF의 Noto Sans CJK KR 글꼴 부분집합 5개 모두 내장되어 있고 Unicode 매핑을 포함함 |
| 핵심 수치 | 참가자 114명, 대화와 진료 완료 98명, 사전 기준에 따른 중단 0건, 환각 1건, 임상 정보를 추가한 5개 대화를 유지함 |
| 연구 조건 | 모든 AI 대화에 대한 의사 감독, 비교군 없는 단일군 실행가능성 연구라는 조건을 유지함 |
| R2 범위 축소 | `미국`, 영어 사용 성인 또는 English-speaking/adult 인구 집단 표현이 두 산출물에서 검출되지 않음. 일반 외래환자 전체로 확대하지 않는 문구를 유지함 |
| 내부 메모 제외 | `담당자 메모` 표기 없음. R2의 방문 도입 문구·설명·Q&A·금지 주장에 해당하는 별도 메모 문자열 19개가 DOCX XML과 PDF 본문에 포함되지 않음. 공개 본문과 의도적으로 겹치는 claim map은 유출 판정에서 제외함 |
| 출처 링크 | `https://pubmed.ncbi.nlm.nih.gov/42849491/`가 DOCX 외부 링크와 PDF 링크 주석에 모두 존재함. 링크 대상 재조회는 이번 검증 범위가 아님 |

비차단 관찰: 예시와 유의사항을 함께 배치하는 기존 템플릿 때문에 1페이지 하단 여백이 넓다. 1페이지에는 본문 끝의 `[S3]`와 별도 출처 행의 `[S3]`가 반복된다. 내용 손실이나 읽기 장애는 없으며 요청된 읽기 전용 검증에 따라 수정하지 않았다.

**확인 범위:** 산출물의 레이아웃·편집성·본문 보존·내부 메모 분리만 검증했다. 논문 전문이나 연구 원자료를 검증했다는 뜻이 아니다. 산출물에는 PubMed 수록 초록·서지정보·이해상충 정보까지만 확인했으며, 출판사 전문의 구체적인 중단 기준과 전체 평가 항목은 미검토라는 한계가 그대로 표시되어 있다.

검토 이미지: `qa-docx-r2/page-1.png`, `qa-docx-r2/page-2.png`, `qa-pdf-r2/page-1.png`, `qa-pdf-r2/page-2.png`.

재현 도구: Codex 번들 Python, `render_docx.py`, 번들 `dependencies/bin/override/soffice`, 번들 `dependencies/bin/override/pdftoppm`; 구조 확인에는 python-docx 호환 OOXML 및 pypdf를 사용했다. 기존 파일의 읽기 전용 QA이므로 문서 생성·편집 마커를 실행하지 않았다.
