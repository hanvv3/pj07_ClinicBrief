# 조사 결과의 한국어 문체 확인

사용자는 환자 메시지 연구를 설명한 ‘AI 답장 초안을 실제 사용한 회신은 더 짧은 회신 경과시간과 연관됐다’가 부자연스럽다고 지적했다. 실제 저장된 `ready_to_use.body`와 일치했다. 이전 12개 비교는 `compose()`만 실행했으므로 이 조사 결과 경로의 품질을 보장하지 않는다.

원문은 [JAMA Network Open 연구](https://jamanetwork.com/journals/jamanetworkopen/fullarticle/2856029)다. 환자 메시지 제출부터 첫 답장 발송까지의 시간, 첫 사용 이후와 개별 초안 사용의 차이, 1,542명·983,154건·8.6%·−29.5%와 관찰 연구라는 범위를 본문에서 확인했다.

## 확인 방법과 중간 결과

원래 조사 보고서는 저장되지 않아 공개 근거와 선정 기록으로 앞 네 단계를 재구성했다. 따라서 원래 요청을 그대로 재현한 실험이나 새로운 웹 조사는 아니다. 실제 `discover_insights()`의 최종 작성·검수 코드를 실행하고 요청·응답·사용량을 보존했다. 기존 DB에는 시험 결과를 쓰지 않았다.

| 시도 | 고정한 조건 / 변경 | 관찰 |
|---|---|---|
| 기존 작성 | `gpt-6.1-sol`, 같은 근거·선정 | 추상적인 통계 표현과 반복 설명이 남음. 검수는 통과 |
| 편집 지침 수정 | 같은 모델·입력, 전체 초록 항목 요구를 완화하고 비교 예시 추가 | 여전히 ‘경과시간이 짧은 것과 연관됐다’. 이 수정만으로 해결됐다고 판단하지 않음 |
| 본문 출력 순서 변경 | 수정된 지침 유지, 본문을 근거보다 먼저 출력 | 같은 문제가 남아 순서 변경은 되돌림 |
| 모델 변경 | 수정된 지침과 원래 출력 순서 유지, `gpt-6-astra` 사용 | 문장이 일부 달라졌지만 추상 표현·한계 나열은 남음. 기본 모델은 바꾸지 않음 |
| 별도 문장 편집 | 앞서 생성한 Sol 초안 그대로 재사용, 편집·최종 검수만 Sol로 추가 실행 | 첫 문장이 ‘환자 메시지에 AI 답장 초안을 쓴 경우에는 첫 답장이 더 빨리 나갔습니다’로 바뀜. 최종 사실 검수 통과 |

앞 네 조건은 한 번 생성하고 한 번 검수했다. 마지막 조건은 기존 초안을 고정하고 편집과 검수만 새로 실행했다. 자연 생성의 변동을 분리할 반복 실험은 아니며, 모든 자동 검수가 통과했다고 해서 문체가 좋았다고 해석하지 않는다. 특히 더 강한 모델도 실패했다는 관찰은 그 모델의 전체 한국어 능력이 부족하다는 증거가 아니다.

## 적용한 경로 변경

조사 결과의 근거 정리와 독자용 문장 편집을 별도 요청으로 나눈다. 편집에는 독자·용도·확인된 사실·기존 문안만 전달하고, 조사 보고서와 선정 과정의 지시는 제외한다. 편집자는 공개 문장만 바꿀 수 있고 출처·주장·선정 기록·자료 형식·적용 조건은 보존한다. 최종 사실 검수는 편집 후 문안을 받는다. 주제 최대 세 개를 한 번에 편집하므로 조사 전체 상한은 6회에서 7회로 늘고, 자동 재시도는 없다.

사용자가 실제로 거절한 표현과 제안한 방향은 [피드백 사례](../../evals/editorial/human-feedback.json)에 보존했다. 이 사례를 조정에 사용했으므로, 같은 사례의 결과는 새 주제의 품질이나 사용자의 만족을 입증하지 않는다.

작성 맥락·버전 이름을 주지 않은 별도 독자 평가 에이전트도 편집 후 글을 선호했다. 첫 문단이 결과를 바로 설명한다는 이유였다. 다만 ‘전체적으로 통계적으로 유의한 감소’라는 후반 문장과 반복 결론은 여전히 어색하다고 지적했다. 제목의 ‘전체 회신 개선’도 측정한 시간보다 넓게 읽힐 수 있다. 실제 사용자의 수정본 평가는 아직 없으며, 이 지적을 숨기고 완성도 5점으로 처리하지 않았다. 수정 전 문장의 ‘분석 단위가 다르다’ 역시 제공 근거만으로는 뒷받침이 부족하다는 평가를 받았다.

## 실행 확인

- 실제 유료 요청 10회, 응답에 보고된 사용량 합계 62,580토큰. 실패 숨김·자동 재시도 없이 모든 시도를 보존했다. 토큰 수는 청구 금액이 아니다.
- 편집 단계의 ID 연결·근거 불변·편집 후 검수·실패 시 재시도 없음 등을 포함해 전체 184개 테스트 통과. 처음 제한된 실행 환경에서는 로컬 소켓 권한 오류가 있었고, 올바른 가상환경과 로컬 서버 허용 환경에서 전체 통과를 확인했다. UI 테스트와 공백 검사도 통과했다.
- 별도 코드 검토에서 추가 편집 경로의 수정 필요 사항은 발견되지 않았다. 이 검토가 실제 문체 품질을 보장하는 것은 아니다.
- 진행 중인 작업이 없음을 확인하고 로컬 서버를 재시작했다. `/`와 `/api/session` 응답 200, 기본 모델 `gpt-6.1-sol` 유지. 새 조사부터 별도 편집 단계를 거친다.

실험 기록은 `.local-data/evals/wording-2026-11-08/`, `wording-order-2026-11-08/`, `wording-model-2026-11-08/`에 있다. 별도 편집 경로 확인은 `wording-edit-2026-11-08/`에 보존한다. 각 기록은 입력의 재구성 여부와 실제 요청 횟수를 구분하며 키·인증 헤더를 포함하지 않는다.
